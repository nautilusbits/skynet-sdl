# Pickups

## What is a pickup

- At map start FUN_0011d600 gives act **0xFD** to every variant-3 sprite
  whose sprite index (bank << 7 | record) is listed in the **item table at
  0x35800**. Bank membership alone is not the rule: sprites in the
  weapon/equipment banks (TEXTURE.200, 201, 214) that the table omits stay
  plain scenery.
- Handler **0x11d670** collects it when the player is within 80 units
  horizontally (0x50) and 160 vertically (0xa0).

## Effect of a pickup

Each item table entry gives `[pool, amount, heal %, armour (16.16), weapon,
message key]`:

- `pool += amount`, capped at the pool's maximum (pool table, see
  [weapons-ammo.md](weapons-ammo.md#ammo-pools-initial--max));
- heal a percentage of the bar (health items in bank 214, records 10, 9,
  8, 7);
- add armour (bank 214, records 0-3);
- weapon: set the owned bit and **select** it;
- print the STRINGS.PRS line named by the message key (first definition
  wins) in the top-left status line (the 0x51600 queue, 210 ticks);
- sound 0xB3 (179);
- the pickup is **always consumed**, even when nothing could be added.

Pickups never change the secondary (thrown) selection.

## Drops

Destroying an object (FUN_00124293 / FUN_00123fbd) may drop items:
destruction type table 0x424d6 (v1.00 0x423d6; 14 bytes per type: four effect sprites,
spread, drop type, sound) and drop lists at 0x42c7e (v1.00 0x42b7e; type 3 = ammo, type
4 = medkits/armour). Crates with HP 50 and act 0 just vanish.

## Godot port

- `pickup.gd`: `GRAB_RANGE_H` 80, `GRAB_RANGE_V` 160, `PICKUP_SOUND_ID`
  179; a sleep/wake scheme (`WAKE_RANGE` 3000) for maps with many pickups.
- `pickup_data.gd`: generated by `tools/gen_pickup_data.py` from the
  executable (item table, drop lists, destruction types, sprite ambient
  sounds 0x4cc00).
- Billboards from `level_loader.gd::_build_sprites`.
- Multiplayer: crate drops are server-owned pickups.

## Deviations in the Godot port

- Pickups bob (presentation only).
- Percentages of the health items are taken from the table but were not
  verified in play.
