# skynet-sdl

A C# + SDL3 port of the 1996 XnGine shooters by Bethesda Softworks —
*SkyNET* and *Future Shock* — the successor of the frozen
[skynet-godot](https://github.com/nemo22/skynet-godot) port.

This repository carries **releases only** for now; the source will follow.
The builds contain no game data: they read **your own copy** of the
original game.
